Arquitetura Serverless — Todo App (neshiku.com.br)

AWS (Lambda + API Gateway + DynamoDB + S3 + CloudFront) + Cloudflare (DNS / Proxy Reverso / HTTPS)

Legenda

Fluxo permitido (HTTPS/443, autenticado quando aplicável)
Fluxo bloqueado por firewall/controle de acesso

Controles de segurança aplicados por camada:

  • Cloudflare: único ponto de entrada público — só ela conhece o "segredo" X-Origin-Verify da API e é quem tem os CNAMEs oficiais
  • API Gateway/Lambda: rejeita (403) qualquer requisição sem o header X-Origin-Verify correto — bloqueia acesso direto à URL da AWS
  • S3: buckets 100% privados, "Block Public Access" ativo — leitura só é permitida ao CloudFront via Origin Access Control (OAC)
  • DynamoDB: nenhum endpoint público/porta aberta — acesso só via API AWS assinada (SigV4) pela IAM Role do Lambda, restrita a esta tabela
  • Protocolo único de borda: HTTPS/443 (TLS) — HTTP sempre redirecionado; certificados emitidos via AWS ACM (validação DNS)
  • Portas: 443 (HTTPS, único caminho público) · Lambda→DynamoDB e CloudFront→S3 usam a API interna da AWS, sem porta/IP público exposto
  • Regra geral aplicada em todas as camadas: tudo bloqueado por padrão, exceto o estritamente necessário para o funcionamento
